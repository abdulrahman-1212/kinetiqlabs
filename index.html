The Roadmap

Transparent, validated, and honest.

We don't hide behind a black box. We show you exactly what is validated for production, what is experimental, and what is in development.

OBSERVE

Task Performance Trending Validated

Monitors end-of-task tracking error using sliding-window OLS significance testing. Avoids the compounding false-positive rates of naive thresholding. Ready for design partners.

DIAGNOSE

Per-Joint Parameter ID Experimental

Estimates physically meaningful dynamic parameters from joint telemetry. Current experiments show that closed-loop identification is strongly affected by parameter/regressor coupling, so these estimates are not yet suitable for automated diagnosis.

UNDERSTAND

Embodiment Drift Estimation Research

Connecting performance degradation to changing friction, backlash, and transmission behavior. Researching how to identify these changes online from closed-loop telemetry.

ADAPT

Kinetiq Runtime (Inference SDK) In Development

A runtime layer that applies physics-aware corrections or constraints at inference time. Enables policies to adapt to changing robot dynamics without retraining.
